08 / 09
Map Each Event Type To One Architectural Hook
Webhooks earn their cost when each event type maps to a deliberate downstream action.
session.started
Kick off external workflow tracking. Start a timer for SLO monitoring.
outcome_evaluation.end
Update the progress dashboard. Capture the rubric verdict to your audit log.
dream.completed
Open a review ticket. Block auto adoption until a human signs off.
session.interrupted
Run cleanup. Reconcile partial state. Page on call if budget exceeded.
If an event has no mapped action, do not subscribe. Noise drowns signal.

09 / 09
Diligence For The Next Managed Primitive
Four questions to ask any future managed announcement, before the slide deck has cooled.
Q1
What is the lifecycle?

States, transitions, terminal conditions. If the docs cannot draw it, the abstraction is not real yet.

Q2
What is the SLA gradient?

Research preview, public beta, GA. Different commit risks. Bundles often hide the weakest tier.

Q3
What shared resources?

Container, filesystem, network, state. Whatever is shared is your concurrency problem.

Q4
What is the audit surface?

What is auditable. What is opaque. Regulated verticals stop or start here.

Four questions before commit. Same four questions next release cycle.
